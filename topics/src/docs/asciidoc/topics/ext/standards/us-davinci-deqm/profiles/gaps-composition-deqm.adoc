== Description

The DEQM Gaps In Care Composition Profile defines a document composition consisting of one or more individual MeasureReport(s). Each section of this composition corresponds to an individual MeasureReport for a specific measure. The subject of each individual MeasureReport referenced by the section must be for the same individual specified in the subject of this Composition.
