== Description

A Parameters profile that defines structures of multi-part Parameters to be used for sending [Condition Category Remarks](StructureDefinition-extension-careGapRemark.html) to a [Risk Adjustment Coding Gap Report](https://build.fhir.org/ig/HL7/davinci-ra/StructureDefinition-ra-measurereport.html) using the [PATCH](https://www.hl7.org/fhir/http.html#patch) operation.
