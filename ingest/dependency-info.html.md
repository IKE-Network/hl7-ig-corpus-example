# Maven Coordinates

```

  <groupId>network.ike.examples</groupId>
  <artifactId>ingest</artifactId>
  <version>1-SNAPSHOT</version>
</dependency>
```

## [Apache Ivy](#apache-ivy)

```
<dependency org="network.ike.examples" name="ingest" rev="1-SNAPSHOT">

</dependency>
```
